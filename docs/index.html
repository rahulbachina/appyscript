The Language

Code that reads like
a sentence.

Python punishes you for a missing space. C++ buries logic under syntax. AppyScript uses plain English structure — when, end, say, spin — so kids focus on ideas, not punctuation.

💡
No whitespace errors, ever. AppyScript uses end keywords to close blocks — the same way kids naturally finish a thought. Indent however you like; the compiler doesn't care.
AppyScript
when button_a is pressed
move forward 2s
turn left 90°
end
Arduino equivalent
void loop() {
if (digitalRead(BTN_A)) {
driveForward(2000);
turnLeft(90);
}
}

How It Works

Write → Compile → Run

Three steps from idea to robot. No setup headaches, no toolchain nightmares.

1

Write

Type AppyScript in any editor — or let an AI agent write it for you. The language reads like instructions you'd give a friend.

→
2

Compile

Run appyscript build --target esp32 — the compiler translates your English logic into platform-native code instantly.

→
3

Run

Flash to your device or push to Applaa Home. Your robot spins, speaks, and reacts — exactly as you wrote it.

terminal
$ appyscript build guard_robot.appy --target esp32
✓ Parsed 12 lines
✓ Compiled to Arduino C++
✓ Flashed to ESP32 at /dev/cu.usbserial
🤖 Robot is live.

MCP Server

Every AI can
speak AppyScript.

The AppyScript MCP server exposes the full compiler and language spec to any AI agent. Claude, Cursor, Codex, GPT-4o — one install and they can all generate, validate, and flash AppyScript programs.

Claude
Cursor
Codex
GPT-4o
Appy & Pi
⚡
One-line install. The MCP server ships as an npm package. Add it to your mcp.json and your AI agent gets full AppyScript superpowers immediately.
mcp.json
{
"mcpServers": {
"appyscript": {
"command": "npx",
"args": [
"appyscript-mcp"
]
}
}
}

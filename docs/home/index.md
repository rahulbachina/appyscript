# Applaa Home

Your house is a robot. AppyScript now compiles to smart home devices via the Applaa Home backend.

```appyscript
when start
  set bedroom_light to "blue"
  say "Good evening!"
end
```

Every command flows through a safety guardrail layer — kids can control lights, parents control everything else.

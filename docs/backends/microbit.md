# micro:bit Backend — BBC micro:bit V2

The `microbit` target emits MicroPython for the BBC micro:bit V2. It maps AppyScript `say` and emotion commands to the board's 5×5 LED matrix using the built-in `Image` constants, and uses the `radio` module for board-to-board communication.

This backend is designed for UK Key Stage 2–4 classrooms. The output file is a `.py` script that can be flashed via drag-and-drop as a `.hex` file using the MakeCode editor, or directly over USB using **mu-editor** or the **microbit** Python package.

---

## Supported Hardware

| Item | Detail |
|------|--------|
| Board | BBC micro:bit V2 |
| MCU | nRF52833 (Cortex-M4, 64 MHz) |
| RAM | 128 KB |
| Display | 5×5 red LED matrix |
| Sensors | accelerometer, compass, temperature, microphone, touch logo |
| Radio | Bluetooth 5.0 + proprietary 2.4 GHz packet radio |
| Firmware | MicroPython 2.x (micro:bit runtime) |

---

## Flashing — Drag-and-Drop Hex

1. Write or paste your AppyScript source at [python.microbit.org](https://python.microbit.org) — it wraps the compiled output in an online editor.
2. Alternatively, compile locally and flash with the CLI:
   ```bash
   # install the microbit tool
   pip install microbit

   # flash main.py to a connected board
   uflash main.py
   ```
3. Or use **mu-editor**: paste the compiled output, click **Flash**.
4. The `.hex` approach (drag-and-drop to the `MICROBIT` USB drive) bundles the MicroPython runtime + your script into a single file — handy for classroom distribution.

## LED Matrix and Image Mapping

AppyScript emotion / icon commands map to `microbit.Image` constants:

| AppyScript | Compiled output | Display |
|------------|-----------------|--------|
| `show happy` | `display.show(Image.HAPPY)` | classic smile |
| `show sad` | `display.show(Image.SAD)` | frown |
| `show heart` | `display.show(Image.HEART)` | heart |
| `show arrow forward` | `display.show(Image.ARROW_N)` | north arrow |
| `show arrow left` | `display.show(Image.ARROW_W)` | west arrow |
| `say "hello"` | `display.scroll('hello')` | scrolling text |
| `show number 42` | `display.show(42)` | digit-by-digit |
| `clear display` | `display.clear()` | all LEDs off |

## Generated Code Example

**AppyScript source (`greet.appy`):**

```
when button A pressed:
    show happy
    say "hi!"

when button B pressed:
    show sad
    say "bye"
```

**Compiled output (microbit target):**

```python
# Generated by AppyScript — target: microbit
from microbit import *

while True:
    if button_a.was_pressed():
        display.show(Image.HAPPY)
        display.scroll('hi!')

    if button_b.was_pressed():
        display.show(Image.SAD)
        display.scroll('bye')

    sleep(50)  # polling interval ms
```

## Radio Communications Between micro:bits

The `radio` module lets multiple boards talk to each other — useful for classroom activities like robot swarms or quizzes.

**AppyScript source (sender board, `sender.appy`):**

```
when button A pressed:
    send radio "forward"
```

**AppyScript source (receiver board, `receiver.appy`):**

```
when radio received "forward":
    show arrow forward
    say "moving!"
```

**Compiled output — sender:**

```python
from microbit import *
import radio

radio.on()
radio.config(channel=7, group=42)

while True:
    if button_a.was_pressed():
        radio.send('forward')
    sleep(50)
```

**Compiled output — receiver:**

```python
from microbit import *
import radio

radio.on()
radio.config(channel=7, group=42)

while True:
    msg = radio.receive()
    if msg == 'forward':
        display.show(Image.ARROW_N)
        display.scroll('moving!')
    sleep(50)
```

Channel (0–83) and group (0–255) are set to matching defaults during compilation. AppyScript lets you override them:

```
set radio channel 12 group 5
```

## UK Classroom Context

- The micro:bit V2 is distributed free to every Year 7 student in England through the **Micro:bit Educational Foundation**.
- AppyScript output is compatible with the **KS3 Computing** curriculum objectives for physical computing and sensing.
- Classroom packs (class set of 32 boards) can share compiled `.hex` files via Google Classroom or the school VLE — no USB connection needed per pupil.
- The `radio` feature maps directly to the KS4 **networks and communication** unit.

# Pico W Backend — Raspberry Pi Pico W

The `pico` target emits MicroPython for the Raspberry Pi Pico W. The `applaa_robot_pico` library wraps the RP2040's PIO state machines and PWM channels behind the same `Robot` API used by the other MicroPython backends.

---

## Supported Hardware

| Item | Detail |
|------|--------|
| Board | Raspberry Pi Pico W |
| MCU | RP2040 (dual-core Cortex-M0+, 133 MHz) |
| RAM | 264 KB on-chip SRAM |
| Flash | 2 MB |
| Wireless | CYW43439 — 2.4 GHz 802.11b/g/n + Bluetooth 5.2 |
| Firmware | MicroPython 1.22+ with wireless support |

---

## Flashing MicroPython

1. Download the latest **Pico W MicroPython UF2** from [micropython.org/download/RPI_PICO_W](https://micropython.org/download/RPI_PICO_W/).
2. Hold the **BOOTSEL** button on the Pico W while connecting USB.
3. The board mounts as a mass-storage device (`RPI-RP2`).
4. Drag and drop the `.uf2` file onto the drive — it reboots automatically into MicroPython.
5. Open **Thonny** (or any serial terminal at 115 200 baud) to reach the REPL.

---

## Uploading applaa_robot_pico

```bash
# using mpremote
mpremote connect auto cp applaa_robot_pico.py :/applaa_robot_pico.py

# then upload the compiled script
mpremote connect auto cp main.py :/main.py
```

In Thonny: open the file, then choose **File → Save as… → Raspberry Pi Pico** and save as `main.py`.

## applaa_robot_pico Library

| Method | Description |
|--------|-------------|
| `Robot()` | initialise PWM on GP14/GP15 (left) and GP12/GP13 (right) |
| `robot.move(direction, speed, secs)` | drive motors; blocks for `secs` if given |
| `robot.stop()` | set all PWM duty to 0 |
| `robot.say(text)` | print to REPL / UART |
| `robot.wait(secs)` | `time.sleep(secs)` wrapper |
| `robot.connect_wifi(ssid, password)` | join a network using `network.WLAN` |
| `robot.read_button()` | read the onboard BOOTSEL button (GP23 bridged) |
| `robot.read_temperature()` | read the RP2040 internal temperature sensor |

## WiFi Features

The Pico W's wireless chip unlocks two AppyScript features not available on wired boards:

### Connecting to a network

```appyscript
connect wifi "MyNetwork" password "secret123"
```

Compiles to:

```python
robot.connect_wifi('MyNetwork', 'secret123')
```

Which internally does:

```python
import network, time

def connect_wifi(self, ssid, password):
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(ssid, password)
    for _ in range(20):
        if wlan.isconnected():
            print('WiFi connected:', wlan.ifconfig()[0])
            return
        time.sleep(0.5)
    print('WiFi failed')
```

### Sending sensor data

```appyscript
when temperature > 30:
    send temperature to "http://192.168.1.10/api/data"
```

Compiles to:

```python
import urequests

while True:
    temp = robot.read_temperature()
    if temp > 30:
        urequests.post('http://192.168.1.10/api/data',
                       json={'temperature': temp})
    time.sleep(1)
```

## Generated Code Example

**AppyScript source (`patrol.appy`):**

```
connect wifi "SchoolNet" password "robots2024"
loop forever:
    move forward for 1 second
    turn left for 0.5 seconds
```

**Compiled output (`main.py` — pico target):**

```python
# Generated by AppyScript — target: pico
from applaa_robot_pico import Robot
import time

robot = Robot()
robot.connect_wifi('SchoolNet', 'robots2024')

while True:
    robot.move('forward', speed=80, secs=1)
    robot.move('left', speed=80, secs=0.5)
```

## REPL Debugging

While `main.py` runs on boot, you can interrupt it with **Ctrl+C** in the REPL and inspect live values:

```
>>> import machine
>>> machine.freq()          # confirm 133 MHz
>>> robot.read_temperature()
27.4
```

# CircuitPython Backend — Adafruit Circuit Playground Bluefruit

The `circuitpython` target emits CircuitPython for the Adafruit Circuit Playground Bluefruit. Motor and LED commands use the board's built-in NeoPixel ring and the `adafruit_motor` library.

---

## Supported Hardware

| Item | Detail |
|------|--------|
| Board | Adafruit Circuit Playground Bluefruit |
| MCU | nRF52840 (Cortex-M4, 64 MHz) |
| RAM | 256 KB |
| Flash | 1 MB (+ 2 MB external SPI flash for files) |
| NeoPixels | 10 × RGB NeoPixels built-in, on `board.NEOPIXEL` |
| Sensors | light, temperature, accelerometer, microphone, IR |
| Wireless | Bluetooth LE 5.0 |
| Runtime | CircuitPython 9.x |

---

## Installing CircuitPython

1. Download the latest **Circuit Playground Bluefruit** UF2 from [circuitpython.org/board/circuitplayground_bluefruit](https://circuitpython.org/board/circuitplayground_bluefruit).
2. Double-press the reset button — the board mounts as `CPLAYBTBOOT`.
3. Drag and drop the `.uf2` onto the drive. The board reboots and mounts as `CIRCUITPY`.
4. Install the required libraries from the **CircuitPython Library Bundle** (same version as firmware):
   ```
   CIRCUITPY/lib/
     neopixel.mpy
     adafruit_motor/
     adafruit_lis3dh.mpy
   ```
   Copy these from the bundle's `lib/` folder.

## NeoPixel Colours

AppyScript colour names compile to RGB tuples passed to the `neopixel` library:

| AppyScript colour | Compiled RGB | Notes |
|-------------------|-------------|-------|
| `red` | `(255, 0, 0)` | full red |
| `green` | `(0, 255, 0)` | full green |
| `blue` | `(0, 0, 255)` | full blue |
| `white` | `(255, 255, 255)` | all channels on |
| `off` | `(0, 0, 0)` | all channels off |
| `yellow` | `(255, 200, 0)` | warm yellow |
| `purple` | `(180, 0, 255)` | violet |
| `cyan` | `(0, 255, 255)` | aqua |
| `orange` | `(255, 80, 0)` | warm orange |
| `pink` | `(255, 20, 100)` | hot pink |

You can also pass raw hex in AppyScript:

```
set lights to #FF4500
```

Compiles to:

```python
pixels.fill((0xFF, 0x45, 0x00))
pixels.show()
```

## Generated Code Example

**AppyScript source (`lights.appy`):**

```
set all lights to blue
wait 1 second

when button A pressed:
    set all lights to green

when button B pressed:
    set all lights to red

when shake detected:
    set all lights to white
    wait 0.5 seconds
    set all lights to off
```

**Compiled output (`code.py` — circuitpython target):**

```python
# Generated by AppyScript — target: circuitpython
import board
import neopixel
import time
from digitalio import DigitalInOut, Direction, Pull
from adafruit_lis3dh import LIS3DH_I2C
import busio

# NeoPixel setup
pixels = neopixel.NeoPixel(board.NEOPIXEL, 10, brightness=0.3, auto_write=False)

# Button setup
btn_a = DigitalInOut(board.BUTTON_A)
btn_a.direction = Direction.INPUT
btn_a.pull = Pull.DOWN

btn_b = DigitalInOut(board.BUTTON_B)
btn_b.direction = Direction.INPUT
btn_b.pull = Pull.DOWN

# Accelerometer for shake detection
i2c = busio.I2C(board.ACCELEROMETER_SCL, board.ACCELEROMETER_SDA)
acc = LIS3DH_I2C(i2c, address=0x19)
acc.set_tap(1, 80)  # single tap threshold

# --- program start ---

# set all lights to blue
pixels.fill((0, 0, 255))
pixels.show()

# wait 1 second
time.sleep(1)

while True:
    # when button A pressed
    if btn_a.value:
        pixels.fill((0, 255, 0))   # green
        pixels.show()

    # when button B pressed
    if btn_b.value:
        pixels.fill((255, 0, 0))   # red
        pixels.show()

    # when shake detected
    if acc.tapped:
        pixels.fill((255, 255, 255))  # white
        pixels.show()
        time.sleep(0.5)
        pixels.fill((0, 0, 0))        # off
        pixels.show()

    time.sleep(0.02)  # 50 Hz polling
```

Key points:
- CircuitPython uses `code.py` (not `main.py`) as the auto-run file on the `CIRCUITPY` drive.
- `auto_write=False` is always set so pixel updates are batched — call `pixels.show()` after each fill or assignment.
- The brightness parameter (default `0.3`) is configurable via AppyScript: `set light brightness to 80%` compiles to `brightness=0.8`.

## Deploying

1. Save the compiled output as `code.py`.
2. Copy it to the root of the `CIRCUITPY` drive (appears automatically when the board is connected over USB).
3. The board reloads automatically when the file is saved — no manual reset needed.

```bash
# using circup (CircuitPython package manager)
# install missing libraries first
circup install neopixel adafruit_lis3dh adafruit_motor

# then just copy your file
copy code.py D:\code.py   # Windows, adjust drive letter
```

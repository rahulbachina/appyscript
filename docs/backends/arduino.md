# Arduino Backend

The `arduino` target emits standard C++ for the Arduino framework. The output follows the familiar `setup()` + `loop()` pattern and uses the L298N dual H-bridge driver for motor control.

---

## Supported Boards

| Board | MCU | Notes |
|-------|-----|-------|
| Arduino Uno R3 | ATmega328P, 16 MHz | Most common, 2 KB RAM |
| Arduino Nano | ATmega328P, 16 MHz | Same chip, breadboard-friendly |
| Arduino Mega 2560 | ATmega2560, 16 MHz | More pins, 8 KB RAM |

All three share the same generated output — only the board selection in the Arduino IDE changes.

---

## Hardware Setup

1. Install the **Arduino IDE** (v2.x recommended).
2. Connect the board via USB; select the correct port and board in **Tools**.
3. No extra libraries are required — the generated code uses only `Arduino.h`.
4. Wire the L298N motor driver as shown in the pinout section below.

---

## L298N Wiring

```
Arduino Uno          L298N Module
-----------          ------------
5 V        ─────►  VSS (logic supply)
GND        ─────►  GND
Pin 9  (PWM)──►  ENA  (Motor A speed)
Pin 8      ─────►  IN1  (Motor A dir 1)
Pin 7      ─────►  IN2  (Motor A dir 2)
Pin 6  (PWM)──►  ENB  (Motor B speed)
Pin 5      ─────►  IN3  (Motor B dir 1)
Pin 4      ─────►  IN4  (Motor B dir 2)

External battery (7–12 V) ─► VS (motor supply) + GND
Left motor  leads ──────────► OUT1 / OUT2
Right motor leads ──────────► OUT3 / OUT4

Note: remove ENA/ENB jumpers if you want PWM speed control.
```

## Generated Code Example

**AppyScript source (`demo.appy`):**

```
move forward for 3 seconds
turn left for 1 second
stop
say "hello"
```

**Compiled output (arduino target):**

```cpp
// Generated by AppyScript — target: arduino
// Board: Arduino Uno / Nano / Mega

// ----- Motor pin definitions -----
const int ENA = 9;
const int IN1 = 8;
const int IN2 = 7;
const int ENB = 6;
const int IN3 = 5;
const int IN4 = 4;

void motorsForward(int speed) {
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void motorsLeft(int speed) {
  analogWrite(ENA, speed);
  analogWrite(ENB, speed);
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void motorsStop() {
  analogWrite(ENA, 0);
  analogWrite(ENB, 0);
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void setup() {
  pinMode(ENA, OUTPUT); pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(ENB, OUTPUT); pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
  Serial.begin(9600);

  // move forward for 3 seconds
  motorsForward(200);
  delay(3000);

  // turn left for 1 second
  motorsLeft(180);
  delay(1000);

  // stop
  motorsStop();

  // say "hello"
  Serial.println("hello");
}

void loop() {
  // program ran once in setup(); nothing to repeat
}
```

Key points:
- Sequential scripts compile entirely into `setup()`. `loop()` is empty.
- When an AppyScript `when` (event) block is present, the polling logic moves to `loop()`.
- Motor speed is mapped from the AppyScript 0–100 range to the Arduino 0–255 PWM range.
- `say` maps to `Serial.println` — connect a Serial monitor at 9600 baud to read output.

## Event Handler Example

**AppyScript source:**

```
when button pressed:
    move forward for 1 second
    stop
```

**Compiled output (partial):**

```cpp
const int BUTTON_PIN = 2;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  // ... motor pin setup ...
}

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW) {   // active-low with INPUT_PULLUP
    motorsForward(200);
    delay(1000);
    motorsStop();
    delay(200);  // debounce
  }
}
```

## Uploading

1. Open the Arduino IDE.
2. Paste the compiled output into a new sketch (or open the `.ino` file if saved directly).
3. Select **Tools → Board** and **Tools → Port**.
4. Click **Upload** (Ctrl+U).
